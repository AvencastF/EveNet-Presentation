# Foundation Models for High Energy Physics

AI+HEP Workshop Presentation

## Getting Started

Run from the repository root:

```bash
npm ci
npm run dev -- ICHEP2027
npm run build -- ICHEP2027
npm run export -- ICHEP2027
```

Edit [slides.md](./slides.md) and the files in `slides/`. See the [repository guide](../README.md) for shared components, customization, and deployment.
